# CryloIac — Step 4 provisioning AgentCore project

A **separate** AgentCore project for the privileged provisioning agent, kept apart
from the interactive scan/canvas project (`../CryloCanvas`, which holds Reasoning +
RepoRecon). The IaC agent is the only agent with AWS-mutation authority — isolating
it here gives it its own IAM execution role, deploy lifecycle, and gateway, matching
the design's trust boundary.

## Contents

- **`app/IacArchitect/`** — the Strands runtime that authors / refines the
  CloudFormation template from the build spec Django sends (`generate`/`refine`
  modes). See its own README.
- **`agentcore/agentcore.json.example`** — reference project config: the
  `IacArchitect` runtime + the **`CryloIacGw`** gateway, whose `cfn` target exposes
  the full CloudFormation authoring toolset (`tools.iac.json`: validate, cfn-guard
  compliance, CFN doc search, pre-deploy instructions) plus `docs` + `pricing`. The
  cfn/docs/pricing Lambdas are **shared** with `CryloCanvas` (same ARNs, different
  per-gateway tool scope).

## Scaffolding the deployable project (CLI-generated parts)

The CDK app (`agentcore/cdk/`, `agentcore/cdk/lib/cdk-stack.ts`) and the working
`agentcore/agentcore.json` are generated by the AgentCore CLI and are gitignored —
only `agentcore.json.example` is committed. To stand this project up:

```bash
cd backend/agents/CryloIac
# Generate the CDK scaffold + working agentcore.json for this project. Either:
#   agentcore create --name CryloIac --framework Strands --model-provider Bedrock --memory none
# (then keep the committed app/IacArchitect and reconcile agentcore.json with
#  agentcore.json.example), or copy ../CryloCanvas/agentcore/{cdk,.llm-context,.gitignore}
# and fill agentcore.json from the example.

# Fill the real account id into agentcore/agentcore.json (the example uses <ACCOUNT_ID>),
# then deploy — this creates a separate stack (AgentCore-CryloIac-<target>):
agentcore deploy
```

After deploy, bind **`CryloIacGw`** to the `IacArchitect` runtime so
`AGENTCORE_GATEWAY_CRYLOIACGW_URL` is injected, and set `IAC_RUNTIME_ARN` in
`backend/.env.local`. The `crylo-mcp-cfn` Lambda must be redeployed too (its
`ALLOWED_TOOLS` now permits the full toolset).
